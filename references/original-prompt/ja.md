# XXD Panel 084 原文プロンプト · 日本語読解訳

アップロードした写真を1枚ずつ、独立した上質なデザインポスターにしてください。複数画像を連結せず、各写真を個別に出力します。全体は3:4の縦構図とし、上下2領域の高さを厳密に1:1、各50%にします。

上半分には元写真を残し、主体の同一性、構造、姿勢、実在感のある質感、自然な光と影、元の色彩の雰囲気を保ちます。調整は控えめで上質なカラーグレーディングに限り、アート雑誌、独立系出版物、展覧会写真のような質感にします。画角に合わせて周囲の環境を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、改変したりしてはいけません。

下半分では、写真から最も識別性の高い**主体、輪郭、構造、姿勢、物語上の関係**を抽出し、**ミニマルな線描イラスト＋点描テクスチャ**の芸術画面として再構成します。写実的に描写したり細部を埋め尽くしたりせず、幾何学的かつ構造的な線構成で主体と空間を改めて要約します。黒または濃色の細線で、建築、道路、植物、器物、場面の主要輪郭、遠近関係、視線誘導線を作り、元の対象をひと目で識別するための核だけを残します。

画面言語では**幾何学的な線の骨格＋点による空気のテクスチャ**を強調します。主体と環境を縦線、横線、折線、曲線、遠近線で構成し、線には少しの緩み、手描きの揺れ、軽い不規則さを残して、抑制されながら生き生きした **pen-and-ink linework** にします。その上に広範囲または局所的な **stippling / dotted texture** を加え、点の疎密で空気、光、被写界深度、空間階層を作ります。点は空、地面、遠景、木陰、灯り、主体周辺に分布でき、**density-based stippling** のグラデーションリズムを形成します。

構図では**余白の芸術、幾何学秩序、視覚的重心、方向誘導、図文関係**を重視します。主体を完全に中央へ置く必要はありませんが、明確な焦点は必要です。道路の曲線、建築の遠近線、街灯、電線、樹木、場面境界で自然な leading lines を作ります。複雑な背景は積極的に減らし、少数の重要な形と空間の手掛かりだけを残して、下半分を完全な風景画ではなく、抽出された都市随筆、建築スケッチ、場面構造図のようにします。

上の写真から最も気質があり記憶に残る色を抽出して再編します。全体は**限定色体系**とし、柔らかなブルーグレー、オフホワイト、淡いグレー、暖白など刺激の少ない総合色を中心に、少量の暖黄、金色、または元写真で最も生命力のある色を **spot color / color accents** として加えます。灯り、窓、地面の小さな点、局所的標識、視覚リズムに限って控えめに使います。ブルーグレーの空や淡色背景のような大きく単純な色域を残し、静かで、詩的で、澄み、抑制された画面にします。

文字は少量だけ介入させ、写真の主体、場所、感情、時間感覚、象徴性から短い題名、短文、微細な注記を自由に生成します。言語を固定せず、メニュー式情報にはしません。**細く、静かで、印刷誤差と手作業の不揃いをわずかに持つ軽量文字スタイル**を用い、独立系出版物の小さな編集注記のようにします。文字を余白、主体の縁、視線誘導線に沿って自然に置き、力の抜けた精緻な図文混排を作ります。

全体は **minimal urban illustration、urban sketch-inspired line-and-stipple illustration、architectural line drawing、graphic simplification** を参照し、上質、現代的、静か、詩的、抑制的でデザイン性のある視覚効果にします。写実的な厚塗り、完全な水彩風景、複雑なテクスチャ、太い黒輪郭、カートゥーン感、過剰装飾、安価なフィルター、強いコンピュータ生成感、テンプレート組版は避けます。
