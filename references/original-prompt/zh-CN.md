# XXD Panel 084 原始提示词 · 简体中文原文

请将我上传的每一张照片分别制作成一张独立的高级设计海报，不多图拼接，每张照片单独输出。整体采用3:4竖版构图，上下两个区域高度严格1:1，各占画面50%。

上半部分保留原始照片，保持主体身份、结构、姿态、真实质感、自然光影和原有色彩氛围，仅进行轻微高级调色，使其具有艺术杂志、独立出版物与展览图像质感。为适配画幅，可自然扩展环境背景，但不得拉伸、扭曲或改变主体。

下半部分提取照片中最具识别性的**主体、轮廓、结构、姿态与叙事关系**，重构为一幅 **极简线描插画 + 点描肌理** 的艺术画面。不要写实描摹，也不要把细节画满，而是用几何化、结构化的线性构成重新概括主体与空间：以黑色或深色细线建立建筑、道路、植物、器物或场景的主要轮廓、透视关系与视觉引导线，只保留一眼可识别原物的核心特征。

画面语言强调 **几何线性骨架 + 点状氛围肌理**。主体与环境由竖线、横线、折线、弧线和透视线构成，线条可略带松动、手绘抖动与轻微不规整感，形成克制而生动的 **pen-and-ink linework**。在此基础上加入大面积或局部的 **stippling / dotted texture** 点描肌理，用点的疏密变化营造空气感、光感、景深与空间层次；点可以分布在天空、地面、远景、树影、灯光或主体周围，形成 **density-based stippling** 的渐变节奏。

构图重视**留白的艺术、几何秩序、视觉重心、方向引导与图文关系**。主体不必完全居中，但必须有明确焦点；可通过道路弧线、建筑透视线、路灯、电线、树木或场景边界形成自然的 leading lines。复杂背景主动删减，只保留少量关键形体与空间提示，让下半部分更像一幅经过提炼的城市随笔、建筑速写或场景结构图，而不是完整风景插画。

配色从上方照片中提取最有气质、最有记忆点的颜色进行重新组织，整体采用**限制性色彩体系**，以柔和的蓝灰、米白、浅灰、暖白等低刺激综合色为主，再加入少量暖黄色、金色或原图中最具生命力的强调色作为 **spot color / color accents**，点到为止地用于灯光、窗户、地面细点、局部标识或视觉节奏。可保留大面积单纯色域，如蓝灰天空或浅色背景，使画面安静、诗意、清透而克制。

文字少量介入，根据照片的主体、地点、情绪、时间感或象征意义自由生成简短标题、短句或微型注释，不固定语种，也不采用菜单式信息。字体使用**细瘦、安静、略带印刷误差与手工不齐感的轻量文字风格**，像独立出版物中的小型编辑标注；可沿留白、主体边缘或视觉引导线自然排布，与图形形成松弛而精致的图文混排关系。

整体风格参考**minimal urban illustration、urban sketch-inspired line-and-stipple illustration、architectural line drawing、graphic simplification**，呈现高级、现代、安静、诗意、克制且具有设计感的视觉效果。避免写实厚涂、完整水彩风景、复杂纹理、粗黑轮廓、卡通感、过度装饰、廉价滤镜、强电脑生成感和模板化排版。
